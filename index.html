Expert Speakers

Our speakers work with JavaScript every day. They will share what they have learned and the mistakes they made along the way.

About Full Stack Conf

Full Stack Conf is a one-day event for people who want to learn more about JavaScript, from the front end to the back end.

Come to learn something new, meet other developers and have some free pizza at lunch.

What you will Learn

  • MongoDB How to store and find your data.
  • Express How to build a simple server.
  • React How to build pages from small parts.
  • Node JS How to run JavaScript outside the browser.
  • ES2015 The newer features of JavaScript.
  • Babel How to make new code work in old browsers.
