## Running the Project Locally

1. Clone the repository:
   git clone https://github.com/mufaro-k07/boostrap-challenge.git

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser or use the Live Server extension.
4. Ensure an internet connection is available to load Bootstrap through the CDN.
